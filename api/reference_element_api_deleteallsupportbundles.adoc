= DeleteAllSupportBundles
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser la `DeleteAllSupportBundles` méthode pour supprimer tous les bundles de support générés avec la `CreateSupportBundle` méthode API.



[[parameters]]
== Paramètres

Cette méthode n'a pas de paramètres d'entrée.



[[return-values]]
== Valeurs de retour

Cette méthode n'a pas de valeurs de retour.



[[request-example]]
== Exemple de demande

Les demandes pour cette méthode sont similaires à l'exemple suivant :

[listing]
----
{
   "method": "DeleteAllSupportBundles",
   "params": {}
  },
  "id": 1
}
----


[[response-example]]
== Exemple de réponse

Cette méthode renvoie une réponse similaire à l'exemple suivant :

[listing]
----
{
  "id" : 1,
  "result" : {}
 }
}
----
