= GetRemoteLoggingits
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser la `GetRemoteLoggingHosts` méthode pour obtenir la liste actuelle des serveurs de journaux.



[[parameters]]
== Paramètres

Cette méthode n'a pas de paramètres d'entrée.



[[return-value]]
== Retour de valeur

Cette méthode a la valeur de retour suivante :

|===
| Nom | Description | Type 


 a| 
Distanciles
 a| 
Liste des informations d'adresse IP et de port sur les hôtes configurés pour recevoir les informations de journalisation transmises.
 a| 
xref:reference_element_api_loggingserver.adoc[Serveur de consignation] baie

|===


[[request-example]]
== Exemple de demande

Les demandes pour cette méthode sont similaires à l'exemple suivant :

[listing]
----
{
   "id": 3386609,
   "method": "GetRemoteLoggingHosts",
   "params": {}
}
----


[[response-example]]
== Exemple de réponse

Cette méthode renvoie une réponse similaire à l'exemple suivant :

[listing]
----
{
   "id": 3386609,
   "result": {
      "remoteHosts": [
         {
           "host": "172.16.1.20",
           "port": 10514
         },
         {
           "host": "172.16.1.25"
         }
      ]
   }
}
----
