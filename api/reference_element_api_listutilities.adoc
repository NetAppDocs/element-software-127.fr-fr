= ListUtilities
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser `ListUtilities` la méthode pour lister les opérations disponibles pour une exécution sur un nœud.



[[parameters]]
== Paramètres

Cette méthode n'a pas de paramètres d'entrée.



[[return-value]]
== Retour de valeur

Cette méthode a la valeur de retour suivante :

|===
| Nom | Description | Type 


 a| 
utilitaires
 a| 
Liste des utilitaires actuellement disponibles pour s'exécuter sur le nœud.
 a| 
tableau de chaînes

|===


[[request-example]]
== Exemple de demande

Les demandes pour cette méthode sont similaires à l'exemple suivant :

[listing]
----
{
   "method": "ListUtilities",
   "params": {},
   "id" : 1
}
----


[[response-example]]
== Exemple de réponse

Cette méthode renvoie une réponse similaire à l'exemple suivant :

[listing]
----
{
  "id": 1,
  "result": {
    "utilities": [
      "ResetDrives",
      "ResetNode",
      "RestartNetworking",
      "RestartServices",
      "CreateSupportBundle",
      "DeleteAllSupportBundles",
      "CreateClusterSupportBundle"
    ]
  }
}
----
